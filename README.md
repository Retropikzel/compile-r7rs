Implementation of
[SRFI-138: Compiling Scheme programs to executables](https://srfi.schemers.org/srfi-138/srfi-138.html)
made with POSIX Shell.


No support for -D yet.


Supported implementations:
- capyscheme
- chezscheme
- chibi
- chicken
- cyclone
- foment
- gauche
- guile
- ikarus
- ironscheme
- kawa
- larceny
- loko
- meevax
- mosh
- mit-scheme
- racket
- sagittarius
- skint
- stklos
- tr7
- ypsilon
